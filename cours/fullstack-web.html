Full Stack Web : comprendre l'architecture moderne

Une introduction structurée pour ingénieurs Java expérimentés — sans repartir de zéro.

01

Qu'est-ce que le Full Stack ?

Full Stack = travailler sur plusieurs couches d'une application Web. Une application Web n'est jamais isolée — elle est composée de parties qui communiquent entre elles.

Le flux d'une requête Web

01 · Navigateur

  • L'utilisateur clique dans le navigateur

02 · Front End

  • Le Front End envoie une demande

03 · API

  • L'API transmet la demande

04 · Back End

  • Le Back End traite et renvoie les données
02

Front End et Back End : l'analogie du restaurant

🍽 Au restaurant

Front EndLa salle, le serveur, l'interface avec le client
APILe bon de commande — la communication entre salle et cuisine
Back EndLa cuisine, les traitements internes, la logique

💻 En informatique

Front EndNavigateur Web, interface utilisateur (IHM)
APIProtocole HTTP/REST pour communiquer
Back EndServeur, traitements métier, logique applicative
À retenir — Front End et Back End sont des zones de l'architecture, pas des langages de programmation.

07

API REST et JSON : le langage commun

Le Front End et le Back End communiquent via une API REST en JSON.

GET /api/users/42

Réponse JSON :
{
  "id": 42,
  "name": "Alice",
  "email": "alice@example.com"
}
  • HTTP — protocole de communication sur le Web
    ↗ En savoir plus
  • REST — style architectural : GET, POST, PUT, DELETE
    ↗ En savoir plus
  • JSON — format texte léger et lisible pour échanger des données
    ↗ En savoir plus
  • API — contrat entre Front End et Back End
REST n'est ni Front End ni Back End. C'est le pont entre les deux.

Lexique des acronymes

Les termes techniques employés dans ce cours, en un coup d'œil.

API
Application Programming Interface — interface qui permet à deux logiciels de communiquer entre eux.
REST
Representational State Transfer — style architectural pour concevoir des API, basé sur les verbes HTTP (GET, POST, PUT, DELETE).
HTTP
HyperText Transfer Protocol — protocole de communication standard du Web.
JSON
JavaScript Object Notation — format texte léger pour structurer et échanger des données.
JVM
Java Virtual Machine — machine virtuelle qui exécute le bytecode Java, indépendamment du système d'exploitation.
ORM
Object-Relational Mapping — technique qui convertit automatiquement les objets d'un programme en lignes de tables SQL, et inversement.
JPA
Jakarta Persistence API — standard Java qui définit comment faire de l'ORM ; Hibernate en est l'implémentation la plus utilisée.
IHM
Interface Homme-Machine — l'ensemble des éléments visuels et interactifs avec lesquels l'utilisateur manipule un logiciel.
POO
Programmation Orientée Objet — paradigme de programmation basé sur les classes, objets et l'héritage.
SQL
Structured Query Language — langage standard pour interroger et manipuler les bases de données relationnelles.
